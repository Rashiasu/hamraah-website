# Hamraah Advisors website

Static one-page site for Hamraah Advisors (SMC-Private) Limited, an expert-led study-abroad consultancy (USA focus, plus Europe). No build step: Vercel serves the files as they are.

- `index.html` page content
- `styles.css` brand styling (maroon #6B1E2E, deep #2A0C13, gold #C9A55A; DM Serif Display + Inter)
- `main.js` menu, scroll effects, booking form (sends the request via WhatsApp or email). WhatsApp number and email are constants at the top.
- `assets/logo/` logo SVGs from the brand kit

Deploy: import this repo in Vercel (Framework preset: Other, no build command). Each push to `main` redeploys.
